How to read this syllabus

A path from portal to pipeline

A lot of Azure outlines read like a directory of service names with no thread connecting them. This one is ordered the way you would genuinely bring a workload to life on Microsoft Azure: you begin with the cloud and Linux fundamentals, spin up virtual machines, wrap them in a virtual network, attach storage and databases, secure everything through Entra ID and Defender, then move into serverless, containers with AKS, and automated delivery through Azure DevOps. Every module below expands into a short note on why it appears where it does and what you will have running by the time you finish it — not merely the topics listed inside.

The 24 modules span thirteen tracks. Newcomers should work straight down the list; if you already ship on Azure and only want to close specific gaps, use the filters above to jump to Networking, Security, CI/CD Pipelines or Infrastructure as Code. Each module is taught hands-on against a live subscription, and the sequence mirrors how real environments are assembled in NareshIT's project labs in Hyderabad, where the DevOps and container modules tie the whole curriculum together.
