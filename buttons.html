cloudinit/buttons
UI — BUTTON SYSTEM

Every button, one contract

Effects are opt-in through a single data-fx attribute and compose freely — data-fx="shimmer magnetic ripple" stacks all three. Transform ownership is split across three layers so no two effects ever write the same property. Everything below degrades to a plain, usable button without JavaScript, and drops decorative motion entirely under prefers-reduced-motion.

variants
primary Download

Solid accent fill. The default page CTA.

ghost Read the log

Glass fill with a hairline border, for secondary actions.

sizes
Small Base Large

.btn--sm · .btn--lg · .btn--block

css effects — no javascript
shimmer Hover me

A light band sweeps the face on hover. GPU transform only.

scanline Hover me

A CRT line wipes downward — the terminal-flavoured shimmer.

fill Hover me

Outline button whose background wipes up from the baseline, inverting the label.

gradient Hover me

Conic gradient rotates behind a masked 1px frame via @property.

slide Continue

Trailing icons nudge forward, leading icons nudge back.

pulse Start free

Expanding attention ring. One per page, maximum.

gsap effects
magnetic Pull me

Cursor drags the shell, capped so it never leaves its hit area. Releases on an elastic ease. Tune with data-pull.

tilt Tilt me

3D rotation toward the cursor in perspective. Tune with data-tilt.

letters Staggered

Per-character lift on a stagger. Keeps an aria-label so the label isn't read letter by letter.

ripple Click me

Expands from the exact pointer coordinate, sized to reach the furthest corner.

glow + halo Bloom

Inner highlight tracks the cursor; an outer blurred bloom fades in behind.

confetti

Particle burst on click, driven by a GSAP timeline. Self-cleans every node.

async states
loading → done

Driven by the public API: CloudBtn.setLoading(el) then CloudBtn.setDone(el,{confetti:true}). Sets aria-busy and keeps the button width fixed so nothing reflows.

disabled

disabled or aria-disabled drops pointer events and all effects.

lottie icon

Plays a Lottie JSON on hover. lottie-web is fetched only when a page actually uses it, and the slot is removed if the CDN fails.
