02 The service

Cloud iNIT is a platform that boots cloud infrastructure across AWS, Azure, and Google Cloud through a fixed, auditable sequence of stages — from base image through identity, networking, and service startup to a running sandbox. The service includes:

  • A public marketing and documentation site (cloudinit.online).
  • A test sandbox environment (test.cloudinit.online) for trying the boot sequence.
  • An open API, documented on GitHub, for programmatic access.
  • Downloadable client software for supported platforms.
  • A public status page reporting uptime and incidents.
