read this before you download

Cloud iNIT ships one build per platform. Check your machine against the rules below first — an unsupported system fails at install, not at first boot.

Windows

  • Windows 10 or Windows 11 only, 64-bit. These are the only versions the installer supports.
  • Windows 8.1, 8, 7 and anything older will not install, and will not be patched to.
  • Some older machines are fine. Age of the laptop or desktop does not matter — if it runs Windows 10 or 11 with 4 GB of RAM, it is supported.
  • Keep Windows updated, and allow the installer through SmartScreen and any admin prompt.

macOS

  • MacBook with Apple silicon only — M1, M2, M3, M4 and later chips.
  • Intel-based Macs are not supported. There is no Intel build.
  • macOS must be up to date. Install every pending system update before you run the installer.
  • On first launch use right-click → Open, then allow it under Privacy & Security if Gatekeeper holds it.

Check yours — Windows: Settings → System → About. Mac: Apple menu → About This Mac; the Chip line must read Apple M-something.
