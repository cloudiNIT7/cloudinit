read this before you download

Cloud iNIT ships one build per platform. Check your machine against the rules below first — an unsupported system fails at install, not at first boot.

Windows

  • Windows 10 or Windows 11 only, 64-bit. These are the only versions the installer supports.
  • Windows 8.1, 8, 7 and anything older will not install, and will not be patched to.
  • Some older machines are fine. Age of the laptop or desktop does not matter — if it runs Windows 10 or 11 with 4 GB of RAM, it is supported.
  • Keep Windows updated, and allow the installer through SmartScreen and any admin prompt.

Check yours — Settings → System → About. The Edition line must read Windows 10 or Windows 11, and System type must be 64-bit.

What you are getting

Runs the full nine-stage sequence against shared accounts we manage across AWS, Azure, and GCP. Rate-limited, and it goes through a short automated review before activating, because capacity is shared with everyone else on the same release window. That trade-off is what keeps it free.

  • Activates after a short automated review within this release window
  • Rate-limited, since capacity is shared
  • Needs no cloud credentials of your own
  • Auto-expires at the end of the release window

Installing on Windows

  1. Run the downloaded .exe. SmartScreen may warn on a fresh build — choose More info → Run anyway.
  2. Approve the administrator prompt so the boot-engine service can register.
  3. Launch Cloud iNIT and watch the first boot stream all nine stages.
  4. Uninstall from Settings → Apps, not by deleting the folder, so sandboxes tear down and credentials rotate.
